# 游戏内控制菜单实验

用户期望在游戏内选天气、武器和载具。这里的 `RoeControlPanel.lua` 是未安装的原生面板逻辑原型：复用泰服 `EuReportWindowPanel` 的现有 6 个选项、确认和关闭事件，分页列出 24 种天气、20 种枪械及吉普车。武器默认一把及 60 发匹配弹药，吉普车默认距离 6 米。它没有复制或分发原版界面资源。

现有客户端资源中可核对 `PanelLogic`、`This.mc.checkbox0` 至 `checkbox5`、`OnReportButtonClick` 和 `qs.ShowReportWindow`。这只证明原生界面对象和事件在资源中存在，**不证明此原型已被加载，也不证明它能进入游戏画面**。当前没有可靠的自定义 Lua 加载入口；以前的 `ScriptCustom` 和 Preload 诊断均未得到正向执行证据。

原型要求环境提供 `ROEControlSend(command)`，参数分别使用已有服务的 `weather`、`weapon`、`vehicle` 命令字段。缺少桥接时会在面板上提示“控制接口尚未连接”，不会发送或伪造成功。客户端 Lua 到本地服务的桥接机制尚未验证，不能随意假定 Lua 能访问文件、socket 或 HTTP。

下一步：先在用户自有泰服客户端副本中验证 Lua 面板逻辑的确实加载与显示，以及原按钮回调触发；再研究安全的本地命令传输、角色就绪和断开处理，最后再进行天气、拾取和驾驶实机验收。不得覆盖游戏原文件或发布原版 GFX、脚本、资源、捕获记录或内存映像。
